# Learning plan

## Overview

Build a learning path from the learner's goal, prior knowledge, constraints, and
available source material. Progress is determined by demonstrated understanding,
not merely by completing a fixed sequence.

## When to Use

Use for curricula, study schedules, concept sequencing, lesson planning, or
adapting an existing plan after the learner reveals a misconception.

## Workflow

1. State the target capability in observable terms and establish the learner's
   current level with one or two diagnostic questions or tasks.
2. Inventory authoritative source material already available in the workspace;
   distinguish supplied evidence from optional external enrichment.
3. Decompose the target into prerequisite concepts and order them by dependency,
   keeping each learning unit small enough to practice immediately.
4. For each unit, define an explanation, a worked example, active practice, a
   checkpoint, and the evidence required to advance.
5. Adjust the next unit from checkpoint results: remediate a prerequisite,
   vary the representation, or increase difficulty. Do not advance on confidence
   alone.
6. End with the next concrete exercise and a compact progress record that names
   mastered, uncertain, and not-yet-attempted concepts.

## Verification

- [ ] The goal and starting level are explicit.
- [ ] Every unit has practice and a measurable checkpoint.
- [ ] Source-backed claims preserve their provenance.
- [ ] The next step changes when evidence shows a gap or mastery.

## Red Flags

- A long syllabus with no diagnostic step or feedback loop.
- Treating reading or time spent as proof of mastery.
- Introducing advanced material before its prerequisites are demonstrated.
