# Learning source gathering

## Overview

Build a compact source packet for one approved learning objective. Preserve what
each source actually says, its scope and date, and what remains uncertain so the
primary tutor can teach from evidence without outsourcing learner interaction.

## When to Use

Use when an explanation depends on workspace material, project knowledge, or
external sources that have not yet been identified and checked. Do not use for
teaching, assessing, grading, or choosing a different learning objective.

## Workflow

1. Confirm the assigned objective, learner-relevant scope, source constraints,
   and stopping condition. Return a gap if the objective is ambiguous.
2. Inventory supplied workspace and project-knowledge sources before searching
   externally. Prefer primary, official, or course-authoritative material.
3. Retrieve in small batches. Inspect promising sources directly and distinguish
   publication date from the date of the event or claim being described.
4. Record each retained fact with source identity, precise location or URL,
   relevant date, scope, assumptions, limitations, and the objective it informs.
5. Preserve disagreements, changed definitions, null results, and inaccessible
   sources. Label inference separately from source statements.
6. Return a bounded source packet organized around the objective, plus remaining
   evidence gaps. Do not turn it into a lesson or a learner verdict.

## Verification

- [ ] Every retained fact has enough provenance to inspect again.
- [ ] Source authority and relevance are explained rather than inferred from rank.
- [ ] Dates, assumptions, disagreement, and access gaps remain visible.
- [ ] The result contains no teaching script, grade, or mastery decision.

## Red Flags

- Using a search summary as the source instead of inspecting the underlying page.
- Collecting broadly related material that does not serve the assigned objective.
- Flattening conflicting definitions or outdated claims into one certain fact.
