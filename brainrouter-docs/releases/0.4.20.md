**One runtime, evidence that travels, and a product you can run in production.**

0.4.20 is a maturation release. The agent could already do the work; this is the release that makes the work **reviewable, tenanted, and durable** — one bounded turn engine that chooses the smallest topology it needs, reviews that carry the code they are about, memory that improves without regressing, and org/team surfaces built for more than one person.

Full reasoning lives in the ADRs linked from each highlight.

## Highlights

**One runtime, graphs of bounded loops.** Core keeps a *single* bounded turn engine and, on every eligible top-level turn, chooses the smallest eligible topology — `direct`, or a validated per-profile stage graph — with or without a goal. Durable phase plans and saved graphs stay explicit; graph authority and approvals fail closed; optimization is a grounded verifier / counter-metric / rollback graph, not a vibe. One safe execution map, rendered as Desktop Runs and a CLI timeline. ([ADR-040](../decisions/ADR-040-one-runtime-graphs-of-bounded-loops.md))

**The finding carries its code.** A review finding is no longer a pointer to GitHub — it persists its own excerpt and the proposed before/after, redacted on the way in, and renders them in the console. A reviewer decides whether a high-severity finding is real, and sets its status, *without opening the pull request* — and the code still renders after the branch is gone, because it is ours, not fetched. ([ADR-036](../decisions/ADR-036-the-finding-carries-its-code.md))

**Review that reasons over the repository, not the diff.** A deterministic in-scope file inventory as the coverage denominator; expansion from changed code to unchanged call sites using correct-looking siblings as negative controls; findings that say exactly where, computed from the evidence they quoted. ([ADR-033](../decisions/ADR-033-review-that-finds-things-and-says-where.md))

**Production flows: tenanted memory, automatic OAuth, and a PR-security bot.** Every capture is scoped to org + workspace + project on the hot path (and backfilled for legacy rows); a restricted project's memory is enforced in recall so it never leaks to a non-member; repositories link automatically over OAuth with no manual owner; the dashboard gates by org role and shows "ask an org admin" instead of a raw 403; Personal / Team memory with share / unshare, and a guided team-setup wizard. ([ADR-017](../decisions/ADR-017-production-flows-org-team-and-pr-security-bot.md))

**An agent that gets better and cannot get worse.** A skill-reliability lifecycle, structured session reflection, an autonomous consolidation cycle, and confidence-based promotion and compaction — memory that compounds instead of drifting. ([ADR-032](../decisions/ADR-032-an-agent-that-gets-better-and-cannot-get-worse.md))

**A meeting you cannot lose.** Capture, transcribe, and summarize as memory-native, with the server as the system of record: retention you can see and set, chunk-level streaming that survives a dropped connection, and a quota the origin cannot lie about. ([ADR-035](../decisions/ADR-035-a-meeting-you-cannot-lose.md))

**Messages that arrive.** Exact-key session-to-session steering — Brain-offline loopback plus durable, tenant-pinned delivery — with a recipient trust gate and application only at a safe turn boundary. ([ADR-034](../decisions/ADR-034-messages-that-arrive.md))

**And the surfaces underneath.** One workspace across many surfaces ([ADR-029](../decisions/ADR-029-one-workspace-many-surfaces.md)), documents the agent can actually read ([ADR-030](../decisions/ADR-030-documents-the-agent-can-actually-read.md)), and a design skill with capability packs ([ADR-031](../decisions/ADR-031-a-design-skill-and-the-capability-it-belongs-to.md)).
