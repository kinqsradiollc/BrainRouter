# 0.4.22 — a native desktop workbench

0.4.22 reshapes the Desktop workbench around the work a person is about to do.
The native presentation makes Build, Plan, Explore, and Capture clear entry
points while carrying the same context, execution, review, and safety controls
through every workspace surface.

## Changed

- **Task-led start surface.** The home view now establishes the active workspace
  first, then presents four deliberate work lanes instead of treating every
  action as an equal card. Project files, saved knowledge, pull-request state,
  and recent work remain directly reachable below it.
- **One coherent workbench.** Navigation, conversations, the composer, utility
  panels, editor and terminal chrome, Track, and Settings now share system
  typography, neutral platform surfaces, restrained blue primary actions, and
  standard native control shapes. Existing workspace, host, and bridge behaviors
  are unchanged.
- **Readable at every working width.** The layout collapses the start lanes and
  context rows cleanly as the work area narrows, while the semantic theme tokens
  keep the same high-contrast and forced-colors behavior.
- **Mode changes state their consequence.** A compact workbench context row now
  explains each active mode’s scope and the effect of a switch: Chat and Code
  retain the conversation while changing access, Track refreshes project state,
  Meetings keeps capture alive, and Planner and Notes identify their
  cross-project scope.
- **Faster memory recall.** Keyword, file-path, and vector candidate retrieval
  now begin together before their existing ranking and filtering stages fuse the
  results; an unavailable embedder still degrades cleanly to keyword recall.
- **Quieter background panels.** Stateful Desktop side panels now retain their
  local state across a mode change while their host refreshes pause until the
  panel is visible again. Visible panels also coalesce a slow refresh instead
  of stacking bridge requests behind it.

## Fixed

- **Browser development preview.** The preview now supplies the account,
  tooling, pull-request-status, and tool-catalog responses that the Desktop
  shell reads at launch, so visual verification does not show false query-error
  toasts.
- **Cross-mode workspace links.** Workspace references now reach every owning
  mode, including Notes, rather than silently leaving a valid destination open.

not change Desktop host contracts, workspace authority, or production command
behavior.
