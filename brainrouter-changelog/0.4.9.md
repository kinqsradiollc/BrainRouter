# 0.4.9 — A brand-new console, a real Brand Studio, and the brain made observable

0.4.8 gave the agent a runtime; 0.4.9 is about everything *around* it — the
product surface. The dashboard is rebuilt from the ground up on BrainRouter's own
design language, the marketing Home becomes an animated memory-science walkthrough,
there's a full admin **Brand Studio** for social art, the previously-idle **brain
agents** now actually run and report their work, and the whole dashboard can be
deployed to **Cloudflare Workers** as a static export. Plus the auth/session and
API hardening that makes a public deployment safe.

Every item shipped as its own branch → PR → green CI → merge into `release/0.4.9`.
Brain suite green: **554 unit** (+ integration), dashboard build **26/26 routes**.

## A brand-new dashboard (the headline)

- **One design language — "The Memory Instrument."** Retired the old copycat look
  (slash mark / Inter / serif / golden palette) for BrainRouter's own system: a
  single Signal accent `#34C28E`, a Recall-Heat warm→cool ramp, Geist + Geist Mono,
  **depth from neutral elevation instead of flatness, and zero coloured glows**.
  Every route and primitive (cards, inputs, tables, badges, nav) was restyled off
  one token cascade, and the whole authenticated app was swept free of the old
  colour grab-bag so it reads as a single instrument.
- **A modern app shell.** The dated floating toolbar is gone. Signed-in, you get a
  real **sticky top bar** (glass + hairline, mono eyebrow, ghost icon buttons, a
  Signal user chip with a centred search), a **grouped, scrollable sidebar**
  (Workspace / Memory / Graph & Recall / Integrity / System), and a **⌘K command
  palette** to jump to any route or action.
- **Full-bleed animated Home.** The landing page is now an **auto-playing scroll
  slide deck** grounded in real memory science — forgetting → human memory stores &
  processes → BrainRouter's layer-for-layer mapping → the four-stage recall pipeline
  → reinforce/decay recall-heat → a self-typing CLI → the ecosystem → CTA. Each
  slide cites its source; motion is `whileInView` reveals + ambient loops, with
  `prefers-reduced-motion` honoured. A rewritten **/about** (accurate self-host vs.
  hosted framing, a Core Maintainer card, the npm distribution, and a "Desktop app —
  coming soon" surface), and a **code-generated guilloché brand mark** in the navbar.

## Brand Studio (admin-only `/brand`)

A studio for on-brand social art — version-forward release cards, banners, avatars,
logos — better than the canvas-raster tools it was modelled on (everything is true
vector).

- **Freeform Canvas editor** — a vector layer editor: text / logo / image / shape /
  **role-badge** layers with drag-move + corner-resize, centre/edge **snapping &
  guides**, arrow-nudge, double-click **inline text editing**, a layers panel
  (reorder / duplicate / lock / hide) and a per-layer inspector (rich text incl.
  shadow/outline, alignment, brand colour swatches, opacity/rotation, precise
  X/Y/W/H + align-to-canvas).
- **Templates** — Release, Feature, Role card (portrait), **Role banner (wide)**,
  Quote, Logo lockup — each a native-size layered doc you can edit, with role
  badges carrying a per-role icon (Founder / Founding Engineer / Verified / …).
- **Canvas zoom** (−/% /+ and ⌘/Ctrl-scroll) and **platform safe-zone guides** that
  show where the profile photo overlays a banner and which area survives device
  cropping (LinkedIn, Facebook, X, YouTube, Story) — so content is never hidden.
- **Crisp export** — true vector **SVG** (text stays editable) and **hi-res PNG**
  (1×–4×). Admin-gated behind login (non-admins bounce to /overview).

## The brain, made observable + activated (MEM-10b)

Six brain agents that showed "idle · never" on a populated database are now wired:

- **`tree_sealer` / `tree_digest`** — the scene tree now seals a **settled** bucket
  of leaves (a maintenance pass that adds no new leaf) instead of waiting for a full
  bucket that realistic, few-scene users never reach, so sealing + the LLM digest
  actually run. (New `BRAINROUTER_TREE_IDLE_SEAL_FLOOR`.)
- **`source_chunker` / `blackboard_reconciler` / `relevance_judge`** — these do
  their work **inline** (source chunking on ingest, blackboard admission on capture,
  relevance judging during recall) and never left a job row. They now record a
  best-effort observable job so the status panel reflects real activity.
- **`benchmark_eval`** — auto-scheduled from maintenance (early pass + ~daily,
  `BRAINROUTER_BENCH_SCHEDULE=off` to disable).
- The brain-agents panel also labels the mechanical (no-LLM) stages clearly instead
  of a bare "none".

## Auth, sessions & API hardening

- **Refresh tokens.** Sign-in/up issue a 30-day refresh token; access JWTs are
  short-lived with **silent renewal** and **cross-tab persistence** (tokens in
  localStorage), fixing new-tab re-login. New `POST /api/auth/refresh` (rotating) +
  `/signout`; expired access → 401 so the SDK transparently refreshes-and-retries.
- **Static presentation mode** (`NEXT_PUBLIC_BRAINROUTER_STATIC_PRESENTATION`) — ship
  the dashboard as a backend-free product preview (marketing pages only, no API
  calls), or unset it for the full app.
- **API hardening** — fail-closed JWT secret, the `/me` key-leak fix, security
  headers + strict CORS, reusable zod validation, dual rate-limiting + a terminal
  error envelope, and a graceful-shutdown fix so `tsx watch` restarts cleanly.

## Deploy to Cloudflare Workers

The dashboard is fully client-rendered, so it now **exports to static HTML served
by a Cloudflare Worker** (Static Assets) — no SSR runtime, no cold starts. Gated
behind `CLOUDFLARE_BUILD` so the default build is unchanged; `wrangler.jsonc` +
`build:cf` / `cf:preview` / `cf:deploy` scripts + a `DEPLOY-CLOUDFLARE.md` guide.

## Notes

- The brain-agent activation needs a server restart to take effect on an existing
  database (the scene tree builds on the next maintenance pass).
