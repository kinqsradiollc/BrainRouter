# 0.4.21 — the runtime became plug-and-play, and the process became a glass box

0.4.21 is a foundations release. Two things changed underneath everything: the
runtime stopped being a set of hard-wired switches and became a **plug-and-play
system of registrations**, and the agent's whole process stopped being a black
box and became **something a human can watch, inspect, and replay**. On top of
that foundation it ships a live **edge egress tunnel**, completes the
**credential-hardening** program, and closes a batch of concrete **security**
holes.

The theme: the interesting work this cycle was not new surface area — it was
making the parts underneath swappable, observable, and honest.

## Added

### The runtime is plug-and-play (ADR-041)

The end state the architecture had been building toward: every part of the
runtime is now a registration, and the tree a surface boots is composed, not
hard-coded.

- **The switches are gone.** The 98-case MCP tool dispatch and the 66-case
  builtin-tool `switch` both dissolved into registries walked as data
  (`McpToolRegistry`, `CommandRegistry`, `PanelRegistry`, `ApiRouteRegistry`);
  adding a tool / command / panel / route is now one array entry, not a new
  branch. The tool runtime's `this: any` god-object is replaced by a cited
  interface.
- **Capability ports + execution worlds.** Filesystem, shell, and subprocess side
  effects are behind injectable ports; the `local` execution world binds them as
  one swappable unit and is the agent's live default.
- **Provider-native streaming.** Anthropic-Messages and Gemini-generate now stream
  their own SSE instead of falling back to a non-streaming call.
- **A richer session plane.** Sessions can be forked (with lineage), searched, and
  read across (`session_list` / `session_read` / `session_search` /
  `session_reference`, redacted and id-authoritative), and a specific reply can
  carry a thumbs + note.
- **Delegation.** External-agent subagent providers, and **Code Mode** (`run_code`)
  — one program that calls tools as bindings, sandbox-parity and default-off.
- **Composed, dumpable trees.** Host profiles for the four surfaces,
  `--dump-composition`, the default loop-driver as a replaceable row, capability
  presets, universal disposables, and typed service profiles.

### The glass box (ADR-041 D14)

The agent's process is now transparent by construction — the UI shows the truth
rather than a narration of it.

- **A trajectory ledger** — every model call recorded as a step (model, duration,
  tokens, and the tools it requested, each tagged with a semantic render intent),
  with **log-only markers** for approvals and compaction and a shadowed marker for
  context a later compaction dropped. Opt-in, log-only, never in model context.
- **A request inspector** — the exact rendered request (model, route, effort,
  tools, a bounded system-prompt excerpt) for any step, on the desktop and via
  CLI `/inspect` and `/trajectory`.
- **A composition panel** — the dashboard `/runtime` view shows what is actually
  running (built-in tools, providers, extensions, commands, the active loop driver
  and execution world).

### Edge egress at the user's edge (ADR-043)

A live tunnel that lets a request leave from the user's own device rather than the
server — end-to-end: the server data path, the desktop client, dialer selection,
per-org **consent** admin API with a global kill-switch, per-request **telemetry**,
and a "traffic leaves your device" indicator. The tunnel's far endpoint validates
against the same upstream allowlist as server-side egress, so it never widens the
SSRF surface.

### Worktrees the agent can enter (ADR-042)

Multi-root workspace scope and `worktree_*` tools, with gitdir sandbox grants and
an ownership registry — the agent can work in an isolated worktree without the
jail being removed.

## Security

- **Credentials the page cannot read (ADR-037).** The credential-hardening program
  completed across eight slices: revocable sessions, a boot guard, cookie + CSRF
  transport (a readable double-submit token that survives reload), identity out of
  the URL, and API keys + tokens out of `localStorage` into memory. The dashboard
  now persists no credential to storage.
- **Concrete holes closed (ADR-039).** Six real vulnerabilities the taint work
  cited as evidence are fixed: a ~23s-per-comment ReDoS, a local-probe SSRF that
  guarded three paths of four, and three runtime provider SSRFs (embeddings,
  rerank, memory-pipeline chat) now refuse an internal target before dialing. The
  database-first code scanner (default setup) and a typed replay corpus back the
  ongoing engine work.

## Changed

- **Dead surface retired.** ADR-034's three unreached session-messaging exports
  were wired or deleted (`findSessionRouteByKey` routed into the desktop send
  path; a title-wrapper and a never-produced held-store terminal removed), and the
  dead-export ceiling fell with them.

## Notes

This release is byte-neutral for anyone who does not opt into the new
diagnostics: the trajectory ledger and request inspector are off by default, and
the native-streaming and execution-world paths preserve the previous behaviour
when their flags are unset.
