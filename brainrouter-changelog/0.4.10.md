# 0.4.10 — Memory-home hardening, a mobile dashboard, and a real Cloudflare runtime

A focused follow-up to 0.4.9: the memory engine stops writing into your project
directory and gains a couple of escape-hatch flags, the dashboard becomes fully
mobile-responsive and now deploys to Cloudflare as a real Next.js Worker (not a
static export), and the web favicon ships. All published at 0.4.10.

## Memory engine

- **`BRAINROUTER_HOME` override.** A single `getBrainrouterHome()` resolves the
  BrainRouter home directory — `$BRAINROUTER_HOME` if set, else `~/.brainrouter`
  — and every on-disk location (fallback workspaces, the MCP resolve-cache, the
  work tree, vaults) routes through it. Point it at a custom path to relocate
  all of BrainRouter's state.
- **Consolidation no longer pollutes your repo.** `memory_consolidate` used to
  write `user.md` / `feedback.md` / `project.md` / … under
  `<workspace>/.brainrouter/memories/` — inside your project. It now writes them
  to **`~/.brainrouter/workspaces/<encoded>/memories/`** (keyed by a stable hash
  of the real workspace path), so the human-readable consolidation lives under
  the BrainRouter home, not in your source tree. It also **rejects a transient
  work directory** being passed as the workspace, with a clear message pointing
  you at the real project root.
- **`BRAINROUTER_NEURAL_SPARK_ENABLED` opt-out.** Spreading activation (2-hop
  propagation + Hebbian strengthening + synaptic decay/prune) is on by default;
  set it to `false` to rank recall on the plain scored/reranked candidate set
  instead. Mirrors the opt-out semantics of `BRAINROUTER_GRAPH_ENABLED`.

## Dashboard

- **Full mobile responsiveness.** The console now works on phones — fixed
  clipped tables, overflowing code blocks, and the session list; the Brain
  Agents rows stack cleanly on small screens.
- **Cloudflare deploy via OpenNext.** The dashboard now deploys through
  [`@opennextjs/cloudflare`](https://opennext.js.org/cloudflare) — a real
  Next.js **Worker runtime** instead of a static export, so it keeps SSR,
  runtime bindings/secrets, and observability while still serving static assets
  efficiently through the `ASSETS` binding (`wrangler.jsonc` →
  `.open-next/worker.js`). `build:cf` builds the workspace packages then runs the
  OpenNext build; see `DEPLOY-CLOUDFLARE.md`.
- **Web favicon.** `favicon.ico` (16/32/48), `apple-touch-icon`, 192/512 PWA
  icons and a web manifest generated from the guilloché brand mark, wired into
  the root layout metadata (+ `#06120D` theme color).

## Packaging

- **`@kinqs/brainrouter-hooks` is now published** to npm (was private) with
  `react` as a widened peer (`^18.3.1 || ^19.0.0`), so the dashboard resolves all
  of its `@kinqs/*` deps from the registry — which is what lets the Cloudflare
  build run from the dashboard subdirectory.
