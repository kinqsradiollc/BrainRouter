# 0.4.20 — in progress

0.4.20 is a correctness and security release. Most of it came from one week of
things being quietly broken, so the entries below are grouped by what was wrong
rather than by what was added.

The theme running through it: **several of these had been failing for days
without anything saying so.** A review that fell back silently, a bot whose jobs
all failed with the same database error, a deep-review path that could never have
worked in the shipped image. The fixes matter; the pattern matters more, and it
is now written down as engineering rules rather than left as folklore.

## Fixed

- **Deep review could never have worked.** `reviews/source/exactCheckout.ts`
  shells out to `git init/fetch/checkout`, and the brain image
  (`node:22-bookworm-slim`) ships without git. Every exact-revision checkout
  failed — 83 stages recording `EXACT_SOURCE_UNAVAILABLE` against 2 clean — so
  the parser index never ran and deep review ended at
  `DEEP_REVIEW_PREFLIGHT_SOURCE_UNAVAILABLE`. Ordinary PR review hid it by
  silently falling back to a diff-only packet and reporting success.
- **One missing enum value stopped PR review for four days.**
  `ASSURANCE_STAGE_NAMES` has eleven stages; migration 046's CHECK named ten. The
  missing `cleanup` stage runs at the END of every review, so every review died at
  its last stage: 60 failed jobs, 3,629 cancelled triggers, 36 runs stranded.
  Migration 056 adds it, and `migrations.stageParity.test.ts` compares migration
  CHECK enums to their TypeScript unions — in both directions, without a database
  — because the in-memory test store has no constraints and four unit tests
  asserted the failing row succeeded.
- **An interrupted assurance stage could never be retried.** A stage left
  `running` by a crash was read as "unfinished, retry it", the retry reused the
  same attempt number, and the store refused a second receipt id for one attempt.
  Any crash, restart or OOM mid-stage wedged a run permanently. An attempt now
  owns one receipt id for its life; a terminal stage is not re-run.
- **One PR comment could stall the shared brain for ~23 seconds.**
  `parseReviewCommand` ran three copies of `@\S*brainrouter\S*\s+<cmd>` over the
  raw comment body. `\S` matches `@`, so every `@` was a fresh start position:
  8k → 122ms, 16k → 488ms, 32k → 1.9s, and GitHub caps a comment at 65,536
  characters. On a webhook path that answers before any permission check.
- **`connector_sync` failed ~7,000 times on a directory it was about to create.**
  `getWorkspaceStateRoot` resolves through `fs.realpathSync` for its
  symlink-safety guarantee, and realpath throws ENOENT on a path that does not
  exist yet.
- **Aliased workspace profiles now run the plan onboarding promised.** Active
  turns keep the reviewed workspace profile separate from the effective shared
  plan across all 17 profiles. A valid exact plan still wins; an invalid
  higher-precedence exact claim falls back direct instead of silently loading
  an alias. The domain presets' bundled skill-pack metadata is now complete, so
  every untouched profile can pass the same reviewed CLI/Desktop save boundary.
  Onboarding, controller-owned delegation, runtime events, and telemetry carry
  the same two identities without changing saved orchestration modes.
- **A recommendation can no longer authorize a durable workflow.** Ordinary
  turns hide the low-level workflow launch tools. `/build` and `/workflow run`
  bind one exact CLI request to an
  opaque, session-scoped, single-use intent before the cost gate or any durable
  write; cloned, replayed, mismatched, planner-authored, goal-authored, and
  model-authored launches fail closed. The reviewed turn exposes only that
  launch, binds the effective policy and runtime actor, and carries a revocable
  lease through descendants and terminal publication. New phase runs record
  their launch and parent-turn identities without breaking old run files.
  Trusted phase-run resume and background launch are temporarily unavailable
  until their own attempt and execution lifetimes can be recorded. Desktop has
  a host-only in-process seam; no renderer, IPC, or production UI control can
  issue the bearer yet. Production graph launch remains disabled until its
  approval and cumulative-budget gates ship.

## Security

- **Provider-probe SSRF (one full-read, two blind).** `probe-models`,
  `probe-embedding-dim` and catalog discovery took `baseUrl` from a request body
  and fetched it with no host check; the GET variant returned the response body
  to the caller. All three now route through the DNS-pinned upstream policy the
  `/v1` gateway already used. Hosted mode is the fail-closed default;
  `BRAINROUTER_UPSTREAM_ALLOWLIST` lets a self-hosted deployment name exact
  origins so local Ollama/LM Studio keeps working.
- **A `#` in a saved endpoint defeated the `/models` suffix.** `appendApiPath`
  split only on `?`, so `http://host/internal#` + `/models` fetched
  `http://host/internal`. The fragment is now stripped before appending.
- **Refresh tokens are revocable.** They were bare signed JWTs with no server-side
  row, so `/signout` did nothing, a password reset left stolen tokens working for
  30 days, and rotation left the old token valid beside the new one. Migration 057
  stores a hash per issued token; presenting an already-rotated token is treated
  as theft and revokes the whole chain.
- **Sign-in throttling is per-account, not only per-IP.** Per-IP limiting does
  nothing about the attack that matters — many hosts, one account.
  `forgot-password`, `reset-password` and `resend-verification` now sit behind the
  strict limiter too; all three send mail for an unauthenticated caller.
- **`config.json` is written `0600`.** It holds provider keys, PATs, trigger
  signing secrets and an inline GitHub App private key, and had no mode — so it
  was `0644` under the common umask.
- **`.git` is treated as a credential directory.** `.git/config` embeds tokens in
  remote URLs. Defence in depth; the review path already bounded reads to the
  diff inventory.
- **Every non-breaking dependency upgrade.** 3 critical + 38 high open alerts down
  to 2 + 7. All three criticals were development-scope (vitest, protobufjs) and do
  not ship.

## Changed

- **Meeting audio is durable on a seconds-scale cadence instead of waiting for a transcription
  boundary.** Dashboard and Desktop now persist roughly three-second audio chunks independently
  from the roughly twenty-second units sent to transcription. Recovery, playback and retry assemble
  every referenced chunk; corrupt manifests and sequence holes are preserved for recovery instead
  of being treated as permission to delete audio; paused wall time is not counted as recorded time;
  and captures from the earlier one-file-per-unit format remain readable.
- **Planner is now a working surface in both applications.** Dashboard and
  Desktop render one shared 20-item Today/Calendar implementation with compact
  hierarchy, connected-source provenance and freshness, blocked/estimate state,
  keyboard and drag scheduling, planned-versus-actual capture, conflict choices
  that show both versions, and an inspectable durable sync queue with targeted
  retry. The terminal keeps its own strength: `/planner` is the canonical
  capture/list/complete interface, while `/plan` remains the agent workflow.
- **Notes is one editor, not two drifting renderers.** The full block, page,
  database, quick-find, reference, comment and keyboard presentation now lives
  in `@kinqs/brainrouter-ui`; Desktop and Dashboard supply only host effects.
  Dashboard writes use the authenticated, versioned mutation contract with
  transaction-scoped idempotency, lease grants before typing, fencing,
  compare-and-set conflict clocks and explicit unsupported remote-history and
  attachment-byte capabilities.
- **Planner sync now survives real device races.** Item and time-block writes
  share a validated wire contract; composite paging cannot strand row 1001;
  block tombstones follow item deletion; operation receipts bind keys to exact
  fingerprints; browser and Desktop stores are tenant-scoped; pulled clocks are
  absorbed; pending browser work is replayed over polling; and concurrent text
  plus delete-versus-edit retain both choices until a person resolves them.
- **ADR-038 has release gates proportional to its risk.** Deterministic real
  PostgreSQL scenarios cover two-device Planner convergence and Notes
  transaction rollback/idempotency/lease clocks. A separate Dashboard Chromium
  and native Electron workflow retains screenshots and blocks on density,
  overflow, keyboard, accessibility, sync and source-open behaviour.
- **A learned lesson knows which project it came from.** The store partitions on
  `(orgId, userId)` and nothing else, so repo-specific advice was delivered in
  every other repository. Same-project lessons now rank first and foreign ones are
  capped — ranked rather than filtered, because the portable lessons are the ones
  most worth keeping and no reliable signal separates them.
- **The config path is injectable** (`BRAINROUTER_CONFIG_DIR`), so the write path
  can be tested without writing to a developer's real config.
- **The product presents itself as a workspace rather than an engineering tool.**
  The public pages now lead with the loop a team actually works in — Plan · Meet ·
  Write · Build · Verify · Know — with each stage linking to the route that
  implements it, and engineering framed as the deepest surface rather than the
  whole product. Ten landing components with no importer were deleted rather than
  restyled. Two defects went with the rewrite: three orbit nodes rendered on top
  of the hero headline, and the loop's six scenes were cross-faded through a
  shared window that left two headlines and two paragraphs superimposed at its
  midpoint. The scene fades are now sequenced instead of overlapped.
- **Roughly 5,900 lines of unreachable code were retired** (ADR-028): a workbench
  control layer nothing dispatched, a graph executor and engine selection no user
  path could select, stacking advice for a stacking system this release retired,
  and comprehension and message-receipt paths with no non-test caller. The
  inert-value sweep's orphan and dead-export ceilings fell with them, and they are
  equalities rather than upper bounds so they can only ratchet down.
- **A wedged change now outranks a skewed clock in the sync summary.** For one
  commit the informational clock notice was returned above the stuck-operations
  branch, so the one condition a person can act on was masked by one they cannot.

## Engineering rules

Six golden rules, each earned by one of the failures above: never store a
credential where page script can read it; a fallback must be visible or it is a
silent outage; assert runtime binaries at boot; a SQL CHECK mirroring a TS union
needs a parity test; an interrupted unit of work must stay retryable; bound every
regex over attacker-controlled text.

The meeting recovery work added three more: search prose as well as code when a mechanism is
retired; prove a regression test fails when the protected behavior is removed; and ask which
existing component already knows an exact fact before introducing a tuned proxy for it.

## Decisions

ADR-034 (messages that arrive) is owner-accepted and implementation-complete across Core,
Brain, CLI, Desktop, and its reproducible acceptance command. ADR-035 (a meeting you cannot lose) is accepted and remains partially implemented. D9's
durability/transcription separation and D10's strict capability/checkpoint plus guarded gateway
transport foundation ship in this release, and so does live streaming — off by default. The bundled
sidecar streams by re-decoding a bounded trailing window, the gateway adapter is injected only when
`BRAINROUTER_STT_STREAM_URL` is set, and both hosts ask the endpoint what it offers and pick from
the answer. No shipped compose sets that variable, so out of the box capabilities report
`streaming: null` and the segmented path is unchanged; turning it on has not yet been through
acceptance against a real engine.
D6 (retention a person can see and set) and D11's transcript escrow now ship, and the destructive
host acceptance — kill the process mid-recording, reopen, lose nothing — passes by reproduction on
both hosts with a real SIGKILL and a real browser. The batch transcription path was accepted against
a live engine for the first time in this release: eleven seconds of speech through the bundled
whisper sidecar returned a word-perfect transcript. The streaming path was accepted against the same
live engine: audio fed at microphone pace produced a partial hypothesis 1.4 seconds behind the
speaker — "Dana will present the meeting" — which the final then revised to "Dana will present the
migration plan", which is the whole reason a partial is marked provisional and only the final is
committed. The HOST end was accepted too (`npm run acceptance:meeting-streaming`): the shipped
chain selects streaming from that live answer, degrades to segmented on every incomplete one —
unreachable origin, wrong protocol, unhonourable latency mode, empty mode list — and only
committed coverage moves a resume point, so a stream cut mid-meeting replays exactly the audio
past the checkpoint. D11's audio half is withdrawn rather than deferred. ADR-038 (a planner
worth opening) is
accepted, with one shared Planner/Notes presentation package, a measurable 20-item day and a
blocking two-host visual gate.
ADR-036 (the finding carries its code) and ADR-037 (credentials the page cannot read) remain
proposed and await review. ADR-032 and ADR-033 remain PARTIAL: the deterministic halves are
demonstrated, the live-model halves are not.
