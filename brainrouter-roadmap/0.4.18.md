# BrainRouter 0.4.18 Roadmap — Native Desktop Visual System

**Status:** Accepted; phased implementation in progress ·
**Target:** `release/0.4.18` · **Decision:** [ADR-026](../brainrouter-docs/decisions/ADR-026-desktop-native-visual-system.md)

## Release outcome

0.4.18 is a focused Desktop quality release. It will give the workbench a
platform-adaptive semantic visual system, genuine operating-system window
behavior, system appearance modes, clearer style ownership, and measurable
Editor/Files/panel responsiveness without changing agent authority, browser
isolation, terminal PTY behavior, or orchestration.

The release is intentionally split into small, reversible feature PRs.
ADR-026 was approved on 2026-07-30.

## Release constraints

- Keep the preload-only Desktop capability boundary.
- Keep real platform window controls; do not imitate another operating system.
- Keep inactive right-panel views mounted so navigation preserves state.
- Keep Monaco, browser content, and terminal processes under their current
  owners.
- Do not mix runtime behavior or package restructuring into styling PRs.
- Require live macOS and Windows review before removing the compatibility
  setting.
- Keep 0.4.17 as the latest published version until every 0.4.18 release gate
  passes.
