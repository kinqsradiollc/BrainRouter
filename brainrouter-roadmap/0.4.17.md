## Completed taskboard

- [x] Separate global installation setup from per-workspace project setup.
- [x] Add a typed, committable, secret-free workspace manifest.
- [x] Keep `engineer` as the sole engineering persona and activate frontend
      guidance only for relevant tasks.
- [x] Add reviewed presets, bounded scanning, one structured model proposal,
      deterministic fallback, and confirmation-only writes.
- [x] Make paired global and project writes recoverable, stale-safe, and
      symlink-safe.
- [x] Provide complete CLI and Desktop setup, Skip, Finish Setup, and edit
      re-entry flows.
- [x] Resolve personas, capabilities, skills, tools, briefing, and memory tags
      independently for root and delegated tasks.
- [x] Ship consent-gated profile packs and same-ID specialist executors without
      adding an unconditional frontend executor.
- [x] Add Project-scoped knowledge schema, RBAC, ingest jobs, bounded parsers,
      optional embeddings, scoped retry, retrieval, citations,
      recommendations, and provenance-linked distillation.
- [x] Add Dashboard and Desktop knowledge management with bounded uploads,
      status/retry, citation search, and stale-scope protection.
- [x] Ship each independently reviewable slice through its own hosted CI and
      security disposition before sequential squash merge.

## Acceptance evidence

- An isolated CLI run confirmed global setup chaining, project Skip/no-write,
  engineering save as `engineer` plus `frontend`, edit re-entry, and
  deterministic fallback when the configured model was unavailable.
- Native Electron and responsive browser walkthroughs covered automatic
  onboarding, Skip, retry, save, settings re-entry, instruction include/reject,
  stale-root handling, keyboard behavior, and visible error states.
- Dashboard live QA covered Project selection, base creation, bounded upload,
  asynchronous status, retry, search, citations, and responsive layouts.
- Desktop live visual QA covered the Project knowledge inventory and panel;
  focused host/renderer tests cover credential-free Project resolution,
  zero/multiple matches, create/ingest/status/retry/search, polling, and stale
  response suppression.
- Hosted PostgreSQL/pgvector tests cover cross-organization and restricted
  Project isolation, queue lifecycle, parser bounds, hybrid fallback,
  provenance, and non-recursive distillation.
- The latest integrated release-head CI after the feature program passed the
  complete build/test, lint/typecheck, mobile, dependency-audit, and automated
  security-review gates.

## Remaining release-close work

- version and package metadata reconciliation;
- publish dry-runs and package-content verification;
- final release tag and distribution.

These are release operations, not incomplete workspace-onboarding or
Project-knowledge features.

## Out of scope

- A separate frontend persona or default frontend executor.
- Authorization derived from local paths, workspace tags, or client-supplied
  organization/user identity.
- Automatic model-authored project-file changes without visible review and
  explicit confirmation.
- A second cognitive-memory system for source documents.
