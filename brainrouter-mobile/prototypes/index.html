BrainRouter Mobile — Prototype Gallery

Clickable, standalone prototypes of the React Native (Expo) port of the BrainRouter desktop app. User flows are multi-screen click-throughs (tap the highlighted control to advance); user stories show a feature's key screen + state. Every screen maps to real desktop functionality — nothing here is invented.

Design language: DESIGN-expo.md — "The Memory Instrument" (near-monochrome, one Signal accent, mono for data). Icons are the real desktop set (brainrouter-desktop/src/icons.tsx, DESK-4k). The app is a thin client to a remote host — see technical-doc.md.
